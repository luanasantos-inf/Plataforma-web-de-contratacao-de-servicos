## 📌 Sobre o Projeto

A **Plataforma Web de Contratação de Serviços** é uma aplicação desenvolvida em **React** com o objetivo de simular uma plataforma de contratação de serviços.

A aplicação possui diferentes fluxos de utilização, permitindo que clientes consultem os serviços disponíveis, visualizem seus detalhes, realizem solicitações e acompanhem o status dos pedidos.

Também foi desenvolvida uma área administrativa para gerenciamento das solicitações realizadas pelos clientes.

Para simular o backend da aplicação, foi utilizada uma API hospedada no **JSONBin**, responsável pelo armazenamento e manipulação dos dados utilizados no projeto.

### 🎯 Objetivo

Desenvolver uma aplicação web moderna e responsiva, aplicando conceitos de desenvolvimento frontend, componentização, roteamento, consumo de APIs e gerenciamento de diferentes fluxos de usuário.

## 📡 API

Para simular o funcionamento de um backend, o projeto utiliza o **JSONBin** como uma API externa.

A API é utilizada para armazenar e consultar os dados necessários para o funcionamento da aplicação, permitindo simular operações relacionadas aos serviços e pedidos.

> **Observação:** por se tratar de um projeto frontend com backend simulado, os dados e operações possuem finalidade demonstrativa.
